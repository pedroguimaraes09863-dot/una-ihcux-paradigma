# una-ihcux-paradigma

Code First (para banco de dados)

a) O que é:
O banco de dados é criado a partir do código da aplicação (ex: modelos/ORMs), e não o contrário.

b) Benefícios:

Integração forte entre código e banco
Versionamento mais fácil
Produtividade maior para devs

c) Dificuldades:

Menos controle fino sobre o banco
Pode gerar estruturas não otimizadas
Dependência de ferramentas/frameworks

d) Empresas que usam:

Muito comum em startups e empresas que usam frameworks como:

Microsoft (.NET / Entity Framework)
Google (em projetos com ORMs internos)
